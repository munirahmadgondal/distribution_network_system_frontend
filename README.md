# Distributor Network System Frontend

React + Ant Design frontend using atomic design folders:

- `components/atoms`
- `components/molecules`
- `components/organisms`
- `pages`
- `services`
- `theme`

## Setup

```bash
npm install
npm run dev
```

The API base URL defaults to `http://localhost:4000/api`. Override with:

```bash
VITE_API_BASE_URL=http://localhost:4000/api
```
